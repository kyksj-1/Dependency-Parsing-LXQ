\section{Methodology}
\label{sec:method}

This section presents the architectural choices we study. We keep the description close to the level of detail that a careful reader needs to reproduce the runs, and we defer mathematical analysis to Section~\ref{sec:theory}.

\subsection{Overall pipeline}
\label{sec:method-overall}

The parser instantiates the graph-based dependency parsing pipeline of \citet{dozat2017biaffine} and is composed of four stages applied in sequence. First, a pair of lookup embeddings maps each token into a learned word vector and a learned POS-tag vector that are then summed with a frozen pretrained embedding to form the input representation. Second, a sequence encoder---either the original three-layer BiLSTM or one of the Transformer variants we introduce below---produces a contextualized sequence $\bH\in\mathbb{R}^{L\times d_h}$ where $d_h$ is fixed to 800 across all encoders so that the downstream heads see a uniform interface. Third, two single-layer MLPs project each contextual vector into a head-role representation and a dependent-role representation; a separate pair of MLPs produces the projections used for relation labelling. Fourth, a bilinear attention module produces the arc logits $\mathbf{S}^{\text{arc}}\in\mathbb{R}^{L\times L}$ and the relation logits $\mathbf{S}^{\text{rel}}\in\mathbb{R}^{L\times L\times R}$ used for training and decoding. At inference time we apply the Chu--Liu--Edmonds maximum-spanning-tree algorithm to the arc score matrix and read off the relation label of the surviving edge.

The pipeline is implemented as a single \texttt{ParserModel} module whose contextual encoder is selected at construction time from \texttt{\{lstm, transformer, transformer\_large\}} so that the exact same training loop, data loader, loss function and checkpoint format are reused across all fourteen runs. This is important for the ablations: it forces every comparison to differ only in the component under study, and it guarantees that any accuracy gap is attributable to that component rather than to incidental differences in the training harness.

\subsection{Embedding layer}
\label{sec:method-embedding}

We use two parallel embedding tables for the words. A learned embedding $\bW^{\text{word}}\in\mathbb{R}^{|V|\times d_w}$ is initialised from zero and trained jointly with the rest of the model, with $|V|$ the size of the in-domain word vocabulary. A second embedding $\bW^{\text{ext}}\in\mathbb{R}^{|V_e|\times d_w}$ holds the pretrained skip-gram vectors of \citet{li2018cwv}, where $|V_e|$ is the extended vocabulary that spans the training, development and test corpora; this second embedding is frozen so that the parser inherits semantic knowledge from the pretraining corpus without distorting it. The two embeddings are summed token by token, an operation that \citet{dozat2017biaffine} originally introduced and that we preserve verbatim. POS tags are embedded by a separate 100-dimensional learned table and concatenated to the word representation, yielding an input feature of dimension $d_w + 100$. We follow the original parser in applying \emph{word dropout}, which independently zeros out an entire token embedding with probability $p$, an operation that is strictly more aggressive than standard dropout because it forces the network to reason about contexts in which individual tokens are entirely missing.

\subsection{Encoder variants}
\label{sec:method-encoder}

Three concrete encoders are placed behind the embedding layer and form the central object of our comparison.

\paragraph{BiLSTM encoder.} The original encoder is a three-layer bidirectional LSTM with 400 hidden units per direction, identical to \citet{dozat2017biaffine}. The forward and backward states are concatenated to a 800-dimensional output, and the recurrent transitions use orthonormal weight initialization following the recipe of \citet{dozat2017biaffine} so that the spectral radius of each cell is bounded at initialization. To preserve the variational dropout pattern of the original work, we implement the BiLSTM by hand on top of \texttt{nn.LSTMCell} so that the same dropout mask is applied across all time steps within a sequence. The parameter budget is approximately 13M, dominated by the three stacked LSTM layers.

\paragraph{SDPA Transformer (matched budget).} The first replacement encoder is a four-layer Transformer with a model dimension of 512, eight attention heads, a feed-forward dimension of 1024, and sinusoidal positional encoding. We deliberately match the parameter budget to the BiLSTM at approximately 9M so that the comparison is a clean encoder-family ablation and not a parameter-count ablation. A single linear projection at the input maps the concatenated word-plus-POS embedding to the model dimension, and a single linear projection at the output maps the model-dimension activations back to the 800-dimensional interface expected by the downstream MLPs. The four encoder layers use the default \texttt{nn.TransformerEncoderLayer} with \texttt{batch\_first=True}, which means that the attention key-padding mask is supplied as a boolean tensor with \texttt{True} marking the padding positions. After the final encoder layer we explicitly zero out the padding positions before the projection so that no padding noise leaks into the bilinear scorer; this step is small but important because the bilinear scorer is sensitive to the scale of its inputs.

\paragraph{SDPA Transformer (SOTA, large budget).} The second replacement encoder is an eight-layer Transformer with a model dimension of 768, twelve attention heads, and a feed-forward dimension of 3072, reaching approximately 76M trainable parameters. Beyond the parameter increase, the large encoder also incorporates four families of modern stability and capacity tricks that have been validated across the language-modelling and vision literatures. The pre-norm residual layout of \citet{xiong2020lnorder} replaces the original post-norm layout, allowing the residual stream to carry an identity-like gradient path through the entire stack. Rotary positional encoding of \citet{su2021roformer} replaces sinusoidal encoding, applying a position-dependent rotation to the query and key projections inside each attention head so that the inner product between two tokens depends only on their relative offset. A SwiGLU feed-forward block of \citet{shazeer2020glu} replaces the standard ReLU/GELU feed-forward, replacing the activation--linear cascade with a gated mixture in which the gating branch passes through a SiLU non-linearity. LayerScale of \citet{touvron2021cait} multiplies the output of each residual sublayer by a learnable per-channel scaling vector that is initialised at $10^{-4}$, providing each sublayer with a learnable on-switch that allows the deep network to begin training as a near-shallow network and to ``deepen itself'' as training progresses.

\subsection{Attention layer}
\label{sec:method-attention}

The attention layer inside the Transformer encoder is a multi-head scaled dot-product attention. We rely on PyTorch's fused \texttt{F.scaled\_dot\_product\_attention} kernel, which dispatches at runtime to a FlashAttention-style implementation when the input tensor shapes and dtypes are eligible. The kernel exposes a single boolean key-padding mask that is broadcast across heads and across query positions, and we apply the rotary positional rotation immediately before the kernel by transforming the query and key projections through the rotation in Equation~(\ref{eq:rope}) of Section~\ref{sec:theory}.

The bilinear attention used for arc and relation scoring is mathematically distinct from the encoder-internal attention; we describe it in Section~\ref{sec:theory}.

\subsection{Optimizers}
\label{sec:method-optimizer}

We compare three optimizers across the encoder variants. The Adam optimizer follows the configuration used in \citet{dozat2017biaffine}, with $\beta_1=0.9$, $\beta_2=0.9$ and $\epsilon=10^{-12}$; we note in Section~\ref{sec:experiment} that the unusually small $\beta_2$ is appropriate for the BiLSTM but becomes a source of fragility for the Transformer. The SGD baseline uses learning rate $10^{-2}$ without momentum or scheduling and is included primarily as a negative control. The Muon optimizer \citep{jordan2024muon} introduces a hybrid update rule: every parameter that has at least two trailing dimensions and does not lie inside an embedding table is routed through a Newton--Schulz orthogonalization step on its momentum buffer, after which the orthogonalized update is applied with a per-tensor scale of $\max(1, \sqrt{\mathrm{fan\_out}/\mathrm{fan\_in}})$; every parameter that fails this routing predicate (biases, layer-norm scales, embedding tables) is updated by a fall-back AdamW step. The Newton--Schulz iteration uses the five-degree polynomial coefficients $(a,b,c)=(3.4445,-4.7750,2.0315)$ proposed by Keller Jordan in the original blog post, applied for five iterations after a Frobenius-norm pre-conditioning step.

To keep the Muon implementation usable as a drop-in optimizer, we package the routing logic in a \texttt{MuonWithAdamW} wrapper whose \texttt{from\_named\_parameters} class method takes \texttt{model.named\_parameters()} and emits two parameter groups; the wrapper presents the standard \texttt{step}, \texttt{zero\_grad}, \texttt{state\_dict} and \texttt{param\_groups} interface so that the warmup--cosine scheduler and the gradient clipping logic do not need to be aware that two sub-optimizers are running underneath. The default learning rate is 0.02 for the Muon group and $3\!\times\!10^{-4}$ for the AdamW fall-back group; we revisit this choice in Section~\ref{sec:experiment} where we find it appropriate for the BiLSTM but a factor of four too large for the matched-budget Transformer.
